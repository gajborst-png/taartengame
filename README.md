# Taartenbakkerij

Een bakspel voor kinderen: taarten en cupcakes bakken op bestelling en daarbij lezen, schrijven en rekenen oefenen (niveau groep 4).

Speel online: https://gajborst-png.github.io/taartengame/

Op een Android-tablet: open de link in Chrome en kies "App installeren". Na één keer openen werkt de app ook zonder internet.

Bestanden: `index.html` (het hele spel), `manifest.webmanifest` (app-naam en icoon), `sw.js` (offline werken), `icon-*.png` (app-icoon).
